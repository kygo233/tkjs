# Javbus封面大图v2

- **设置菜单**：点击页面左上角的设置按钮🔨

## Javbus、Javdb

- **封面大图**
- **获取详情页磁力链接**
- **视频预览图**：来自javfree.me和blogjav.net。
- **跳转网站**：自定义跳转网站，跳转到“网址+番号”，只验证是否404，仅支持大部分有码番号。
- **自动翻页**
- **点击复制标题和番号**
- **自适应布局**：支持自适应列数、竖图/横图切换。

## Missav、123av、Jable

- **磁力链接获取**：在列表和播放页添加磁力图标，获取javbus的磁力链接，仅支持大部分有码番号。
