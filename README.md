# svelte-vite Tampermonkey 插件

- 基于 Svelte + vite-plugin-monkey 构建

## 主要功能

### javbus、javdb

- **大图封面**：展示更大尺寸的封面图。
- **磁力链接获取**：获取磁力链接。
- **跳转网站**：自定义跳转网站，跳转到“网址+番号”，只验证是否404，仅支持大部分有码番号。
- **预览图**：支持 javfree.me、blogjav.net 的番号预览图展示。
- **自动翻页**：支持自动加载下一页内容。
- **一键复制**：支持点击复制标题和番号。
- **自适应布局**：支持自适应列数、竖图/横图切换。
- **快捷菜单**：页面左上角设置🔨

### missav、123av、jable

- **磁力链接获取**：在列表和播放页获取javbus的磁力链接
